# Chiến Thắng Điện Biên Phủ 1954

Website giáo dục về Chiến thắng Điện Biên Phủ - "Lừng lẫy năm châu, chấn động địa cầu"

## 📖 Giới thiệu

Website này được phát triển để tôn vinh và tái hiện lại tinh thần chiến đấu quật cường của quân dân ta trong chiến dịch Điện Biên Phủ (13/3/1954 - 7/5/1954), dưới sự lãnh đạo sáng suốt của Đảng Cộng sản Việt Nam và Chủ tịch Hồ Chí Minh.

## 🎯 Cấu trúc Website

Website gồm 5 phần chính:

1. **🏠 Trang chủ** - Giới thiệu tổng quan về chiến thắng
2. **📚 Lý thuyết** - Lời tòa soạn, góc nhìn lịch sử, dấu chân người lính, sức mạnh của Đảng
3. **🇻🇳 Thực tiễn VN** - Điện Biên trong lòng Tổ quốc hôm nay, bài học lịch sử
4. **🎲 Quiz** - Kiểm tra kiến thức về Điện Biên Phủ
5. **🤖 AI Usage** - Minh bạch việc sử dụng AI trong phát triển website

## 🚀 Công nghệ sử dụng

- **React 18** - Thư viện UI
- **React Router v6** - Routing
- **Vite** - Build tool nhanh và hiện đại
- **CSS3** - Styling với animations

## 📦 Cài đặt và Chạy

### Yêu cầu hệ thống

- Node.js 16+
- npm hoặc yarn

### Cài đặt dependencies

```powershell
npm install
```

### Chạy development server

```powershell
npm run dev
```

Website sẽ chạy tại `http://localhost:5173`

### Build cho production

```powershell
npm run build
```

### Preview bản build

```powershell
npm run preview
```
